# 파이썬 · Git 기초 퀴즈

터미널에서 동작하는 4지선다 퀴즈 게임입니다. Python 기본 문법, 클래스, JSON 파일 입출력과 Git을 연습합니다.

## 주제와 선정 이유

파이썬과 Git 기초를 주제로 선정했습니다. 개발 입문 미션에서 배우는 개념을 퀴즈로 복습하기에 적합하기 때문입니다. 기본 문제는 8개이며, 프로그램에서 새 문제를 추가할 수 있습니다.

## 실행 방법

Python 3.10 이상이 필요합니다. 외부 패키지 설치는 필요 없습니다.

```powershell
cd codyssey-quiz
python --version
python main.py
```

`python`이 인식되지 않으면 Python을 설치하고 PATH에 등록하거나 설치된 Python 실행 파일의 전체 경로를 사용하세요. 작업 폴더가 달라도 데이터는 main.py 옆에 저장됩니다.

## 기능

1. 퀴즈 풀기: 전체 문제 출제, 정답/오답 안내, 결과와 최고 점수 갱신
2. 퀴즈 추가: 문제, 선택지 4개, 정답 번호 입력 및 즉시 저장
3. 퀴즈 목록: 등록한 문제 확인
4. 점수 확인: 완료한 게임의 최고 점수 확인
5. 종료: 데이터 저장 후 종료

숫자 입력은 앞뒤 공백을 제거하고 빈 입력, 문자와 범위 밖 숫자를 거절합니다. Ctrl+C와 EOF는 저장 후 종료합니다. 중단된 게임의 점수와 입력이 끝나지 않은 새 문제는 반영하지 않습니다.

## 파일 구조

```text
main.py          실행 시작점
quiz.py          Quiz: 개별 문제, 출력과 정답 판정
game.py          QuizGame: 메뉴, 게임 진행, 저장/불러오기
inputs.py        공통 입력 검증
defaults.py      기본 문제 8개
test_game.py     표준 unittest 기반 검증
state.json       첫 저장 때 생성되는 사용자 데이터
docs/            검증 결과와 제출 안내
```

## 데이터 파일

프로젝트 루트의 `state.json`을 UTF-8로 저장합니다. 사용자 데이터와 백업 파일은 Git에서 제외합니다.

```json
{
  "quizzes": [
    {"question": "정수를 나타내는 자료형은?", "choices": ["str", "bool", "int", "list"], "answer": 3}
  ],
  "best_score": null
}
```

- `quizzes`: 문제 객체 목록. 선택지는 4개, 정답 번호는 1~4입니다.
- `best_score`: 최고 점수 0~100 정수, 미플레이 상태는 `null`입니다.
- 점수는 `round(정답 수 / 전체 문제 수 * 100)`으로 계산합니다.
- 파일이 없으면 기본 데이터로 시작합니다. 손상된 파일은 기본 데이터로 복구하며 다음 저장 전에 `.bak` 파일로 원본을 보관합니다.
- 임시 파일에 쓴 뒤 교체하여 저장 중 원본 손상 가능성을 줄입니다. 읽기·쓰기 오류는 안내 메시지로 표시합니다.

## 검증

```powershell
python -m unittest -v
git log --oneline --graph --all
```

테스트는 임시 폴더에서 실행하여 사용자 데이터를 바꾸지 않습니다. 입력 오류, 퀴즈 추가/재시작, 최고 점수 유지, 0점, 파일 손상, 빈 퀴즈, 중단 및 저장 실패를 검증합니다.

## 구조 설명

`Quiz`는 문제 한 개의 속성과 동작을 묶습니다. `QuizGame`은 여러 문제와 최고 점수를 관리합니다. `__init__`은 인스턴스 초기 상태를 만들고 `self`는 그 인스턴스를 가리킵니다. 메뉴는 `while`, 문제와 선택지 순회는 `for`를 사용합니다.
